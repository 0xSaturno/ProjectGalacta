Bugs and limitations that are already known, check here before reporting one. See [Where do I report bugs?](../faq/#where-do-i-report-bugs) if yours isn't listed.

### Mod Loader

- Mod loading order isn't perfect and can lead to some rare cases where some mods load with wrong priority (mod add-ons not overriding their base mods). Can be fixed using a mod manager like [Repak X](https://github.com/XzantGaming/Repak-X) to rearreange mods priority.
- There are cases were network fluctuations might lead to account reconnection and mod to unload. To fix it is possible to mount mods back with the **F7** key.

### Skin Swapper

- Heroes with multiple forms are not fully supported yet. Playing those while the Skin Swapper is active may cause game instability.
